# The Magic Pearls — Movie Script

A movie script adaptation of *The Magic Pearls*, based on a book written by a
French author in the 1920s.

## Status

🚧 **Early stage.** The script itself has not been committed yet — this
repository currently holds the project license and this description. Drafts,
outlines, and treatment notes will land here as they are written.

## Planned layout

- `script/` — the screenplay drafts (Fountain or PDF).
- `notes/` — research on the source novel, character notes, outlines.
